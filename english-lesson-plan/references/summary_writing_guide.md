# 上海高中英语概要写作高阶指导

## 一、评分标准

- 本题总分为10分，其中内容5分（3大点+2小点），语言5分
- 词数超过60，酌情扣分
- 内容评分关注：内容要点、信息呈现的连贯性和准确性
- 语言评分关注：能否用自己的语言连贯、正确地表述

## 二、任务要求解读

Directions: Read the following passage. Summarize the main idea and the main point(s) of the passage in no more than 60 words. Use your own words as far as possible.

解读：
1. 任务要求你用不超过60个英文单词（不要照抄原文），用自己的话概括所给文章的核心主旨和主要论点
2. 先读文章，抓住"它到底在讲什么"——这就是main idea
3. 再找出作者用来证明或发展这个主旨的几个关键论点——这些是main points

## 三、写作策略

1. 先速览：用10秒锁定标题、首尾段，写出一句main idea
2. 再扫段首：每段首句+转折词(but, however)后的句子，用关键词列3-4条main points
3. 合并压缩：把main idea放在最前，用并列或因果连接main points；删除形容词、副词，保留动词和名词
4. 60词检查：若超限，先删最不重要的point，再砍修饰语，直至达标

## 四、时间安排（建议10分钟）

- 快速阅读原文（2-3分钟）
- 划出关键信息点（通常3+2个）
- 简单草稿paraphrase（2-3分钟）
- 誊写到答题纸（3-4分钟）

## 五、常见语篇模式（结构）与3+2划分法

### （一）总分结构（general-specific）

必要组成部分：
1. General Statement（总论点）——作者开篇提出的核心主张
2. Specific Point（分论点1）——依次展开的支撑细节或例证要点
3. Specific Point（分论点2）——依次展开的支撑细节或例证要点

3+2划分：
- 3大点：General Statement + Specific Point 1 + Specific Point 2
- 2小点：每个Specific Point中的关键支撑细节各取一个

### （二）提问与回答结构（question-answer）

必要组成部分：
1. Central Question（提出的核心问题）
2. Direct Answer 1（对该问题的明确回答1或结论）
3. Direct Answer 2（对该问题的明确回答2或结论）

3+2划分：
- 3大点：Central Question的实质 + Direct Answer 1 + Direct Answer 2
- 2小点：每个Answer中的关键理由/依据

### （三）主张与反主张结构（claim-counterclaim）

必要组成部分：
1. Claim + reason（作者明确提出的核心主张及理由）
2. Counterclaim + reason（对立或质疑该主张的反方观点及理由）
3. Correction（作者新的观点/修正结论）

3+2划分：
- 3大点：Claim + Counterclaim + Correction
- 2小点：Claim的理由 + Counterclaim的理由

### （四）问题解决结构（problem-solution）

必要组成部分：
1. Problem（问题本身及其严重性）
2. Solution（提出的具体解决办法1）
3. Solution（提出的具体解决办法2）

变型：Problem-Cause-Solution

3+2划分：
- 3大点：Problem + Solution 1 + Solution 2
- 2小点：问题的具体表现/后果 + 某一解决方案的关键细节

### （五）因果结构（cause-effect）

必要组成部分：
1. 核心因果链：核心原因（引发后续一系列结果的根本或主要诱因）+ 核心结果
2. 因果关系的层级展开：直接原因与间接原因、直接结果与间接结果

3+2划分：
- 3大点：核心原因 + 核心结果 + 解决方案/结论
- 2小点：一级结果（直接后果）+ 二级结果（间接后果）

### （六）记叙文结构（narrative）

必要组成部分：
1. 核心事件/经历（what happened）
2. 意义/启示/转变（the lesson learned / transformation）
3. 作者反思/总结（reflection / broader implication）

3+2划分：
- 3大点：核心事件 + 意义/启示 + broader implication
- 2小点：事件的关键细节 + 情感/态度转变

## 六、概要写作核心步骤

### Step 1: Main Idea（主旨）
- 用一句话概括文章核心主旨
- 通常涵盖文章的标题句或核心话题

### Step 2: Main Points（要点）
- 根据语篇模式，提取3个大点和2个小点
- 删除例子、数据、转折句等，只留下论点本身

### Step 3: Summary（概要）
- 将main idea和main points合并成连贯的段落
- 使用恰当的连接词（并列、因果、转折等）
- 控制在60词以内
- 使用自己的语言，避免照抄原文

## 七、语言要求

- 使用第三人称和一般现在时（记叙文除外）
- 使用概括性、抽象性词汇
- 使用恰当的连接手段（并列、从属、过渡词）
- 避免直接引用原文句子
- 用自己的话paraphrase
